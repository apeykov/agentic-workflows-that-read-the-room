## Recent updates worth watching

- **Pin Actions dependencies with workflow lockfiles (public preview):** the `gh actions-lock` CLI extension generates `.github/workflows/actions.lock` so onboarded workflows run the exact commits you locked, even if a tag or branch moves. Review dependencies before locking them. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-14-github-actions-workflow-lockfiles-in-public-preview).
- **Agentic autofix for code scanning alerts (generally available):** assign an alert to Copilot and it proposes a fix, reruns CodeQL to validate it, and opens a draft pull request for your review. Available to GitHub Code Security and GitHub Advanced Security customers on GitHub Enterprise Cloud. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-15-agentic-autofix-for-code-scanning-alerts-general-availability).
